# Release 0.8

## Added

- Simulation Engine
- Simulation Pipeline
- Simulation Context
- Detection Phase
- Simulation Clock
- Structured Simulation Events
- DetectedContact model

### Simulation Engine

- Added mission-based detection probability calculation.
- Introduced `DetectionProbabilityCalculator`.
- Detection logic extracted from `DetectionPhase` into a dedicated calculator component.
- Introduced `SubmarineDetectionModifier`.
- Detection probability is now influenced by the assigned submarine role (SSN/SSBN).
- Simulation probability model now supports chained modifiers.
- Introduced `ContactTypeGenerator`.
- Contact generation now depends on the patrol mission instead of being completely random.
- Added `ThreatLevelGenerator`.
- Threat level generation now depends on the detected contact type.
- `DetectionPhase` no longer selects threat levels directly.
- Added `NationGenerator`.
- Contact nation generation has been extracted from `DetectionPhase`.
- Added `ConfidenceLevelGenerator`.
- Contact identification confidence now depends on the detected contact type.
- Confidence generation has been extracted from `DetectionPhase`.
- Added `DetectedContactFactory`.
- Contact construction has been extracted from `DetectionPhase`.
- Contact generators are now coordinated by a dedicated factory.

### Contact Resolution

- Added contact classification status.
- Added `ClassificationCalculator`.
- Added `ClassificationPhase`.
- Contact confidence now determines classification probability.

### Mission Resolution

- Added the `MissionOutcome` model with success, partial success and failure outcomes.
- Added `MissionOutcomeResolver`.
- Mission outcomes can now be derived from detected and classified contacts.
- Outcome resolution remains independent from persistence and REST DTOs.

### Mission Resolution

- Added mission-specific success strategies for every supported mission type.
- Removed the need for generic outcome rules during normal mission resolution.
- Mission outcomes now reflect each patrol doctrine and operational objective.
- Added `SimulationMissionScoreCalculator`.
- Added score penalties for incidents and lost contacts.
- Added unit tests for simulation mission scoring.
- Integrated simulation mission scoring into the application service.
- Simulation REST responses now include `missionScore`.
- Completed the initial mission resolution flow.

### Reporting

- Added `SimulationReportBuilder`.
- Simulation summaries now include mission outcome, score and operational metrics.
- Reporting remains separated from the simulation engine.
- Added `SimulationTimelineFormatter`.
- Centralized simulation event timeline formatting.
- Removed timeline presentation logic from `SimulationMapper`.
- Added `SimulationDebriefBuilder`.
- Simulation responses now include a narrative mission debrief.
- Completed the initial simulation reporting flow.

### Testing

- Added unit tests for contact classification probability.
- Added phase tests for successful and failed contact classification.
- Added unit tests for `SimulationEngine`.
- Verified simulation context aggregation into `SimulationResult`.
- Added automated verification of the ordered simulation pipeline.
- Confirmed phase ordering from transit through patrol completion.
- Added full coverage for mission-based detection probabilities.
- Added submarine-role detection modifier tests.
- Added detection phase tests for successful and failed contact detection.
- Added contact type and contact attribute generator tests.
- Added detected contact factory tests.
- Added coverage for every mission success strategy.
- Added mission outcome resolver delegation tests.
- Added complete simulation REST mapper coverage.
- Confirmed mission outcome, scoring, reporting and timeline mapping.
